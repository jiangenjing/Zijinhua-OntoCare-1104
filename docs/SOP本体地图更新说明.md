# SOP本体地图更新

5120发布包为v2-sop-map，问答实现基于已评测v2。新增的是本体投影、类型目录和流程定义展示，没有把定义图当成业务执行记录。

入口：/ontology/manager#sop；原拓扑上方“业务SOP地图”及侧栏“业务SOP流程”均可进入。

模型包括20个流程定义节点、32条条件分支、9项业务数据绑定、4类材料要求及5项动作声明。流程关联现有订单、商品、物流、产品、知识、工单、经销商、国家和外部材料。数据绑定中的实际记录只是类型示例，不代表对应订单已执行此流程。

节点标注2项已接入、13项部分接入、5项待接入。原图、SOP文字说明、第五节工具要求、工程待核查补充分别标明来源。默认隐藏部分工程补充分支，可勾选显示。

特别补充故障换货前置核查：目标商品在质保内，适用排障完成，问题仍存在。材料SN同时声明适用于故障换货和故障退款。这里表达业务规则，并未修复聊天事实传递或完成换货/退款申请工具。

共享本体服务可发现sop拓扑并查询相同节点、关系和属性；默认仍只读。客服回答代码、检索代码、Prompt及Skill与已评测v2保持一致，但整体runtime会因管理投影模块更新而变化；本轮未重跑548题，不把旧指标说成更新包全量复测结果。
