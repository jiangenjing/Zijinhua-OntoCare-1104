# 本体管理工作台与旧版本关联核查

入口：`http://127.0.0.1:5112/ontology/manager`。在客服主页右侧也有“本体管理工作台”链接。

这是 Rebuild 的只读业务关系投影，复用当前激活本体和本地比赛数据，不修改客服检索算法或旧版数据。它不是 OpenBKN 服务端，也没有实现截图中的 SPARQL、OWL 推理、任意编辑或业务动作执行。

## 可以查看什么

- 拓扑：按实际边聚合成类图；点击类进入实例，点击实例查看局部关系。支持画布移动、缩放和邻居类型筛选。
- 类：产品型号、知识、错误码记录、检查步骤、部件、资格条件、证据、映射、约束、工单、订单、订单商品、经销商共 13 类。默认层级图按“产品与交易、服务与诊断、知识与证据、决策与约束”四个业务分组展示，可展开/收起并切换列表。分组属于展示导航，当前版本没有声明 subclass / is-a 继承。点击类查看属性与关系，随后进入该类全部实例。
- 关系：关系类型、方向、声明基数、字段匹配规则和实际边数；点击后按页浏览关系实例。
- 属性：从实际对象读取字段和数据类型。
- 中文对照：实例与属性列表有独立的中文解释列；保留英文原名，支持按中文搜索。关系起止类、基数、节点详情和工具名称均附中文。875 条 FAQ 的中文标题取自已有中文对照表，生成前逐行核对英文标题、正文和 PN；仅用于展示，不改变检索、本体版本或政策。复现展示标题：`python scripts/build_manager_labels.py`。
- 实例：全部数据可搜索、分页查看；属性详情保留来源。875 条 Q&A 都可检查，其中 3 条隐藏知识不连入客户适用知识关系。
- 校验：发现悬空端点、未知关系、未解析型号、缺失订单和未明确映射的 SKU。没有来源的关系不自动填补。
- 工具与动作边界：展示版本中的实际工具契约；没有退款、换货和发信执行器。
- 旧版关联审计：独立展示 `anker-OntoCare-RSI/OntoCare` 的核查结果。

当前 candidate-1 投影：4,202 个对象实例、6,252 条关系，60 条待核查，0 条结构错误。数字含证据、映射和约束，不等于 4,202 张工单。经销商尚无经过核验的购买渠道关系，保持独立。

## 关联依据

主本体中的关系继承其证据 ID。工单与订单用精确订单号连接，订单与商品用订单号连接，商品与型号仅在 SKU 唯一且精确匹配已收录别名时连接。客户提供的订单号只是提及关系，不表示身份核验成功。

局部图最多展示 50 条匹配边，详情显示前 40 条直接关系。页面明确标出数量，用户可以继续按类型和内容筛选；实例列表和关系列表均可完整翻页。

## 旧版发现

1. 已复现：`resolve_product('我的 E25 报 3212 错误', 'E235311B')` 返回 `E2353`，该产品下适用知识为 0；E25 知识在 `T2353` 下。旧订单 SKU 优先路径存在断联。
2. 已核实：`conversation-graph.js` 将同轮出现的节点按 `same_turn` 连接，不能解释为业务关系或推理证明。
3. 旧导入审计：282 个重复知识 ID，757/930 条步骤父知识不唯一；审计说明这些步骤被排除自动导入，不代表已经错误连接。
4. 旧层生成 26 个产品标识，7 个无适用知识；部分是配件编码，不能自动认定为错，应区分型号和 SKU。

复现：`python scripts/audit_legacy_ontology.py`。脚本只加载旧数据适配器、执行独立的产品解析函数，不启动旧服务器、不加载模型密钥。报告记录所读文件哈希，保存在 `reports/legacy-ontology-audit.json`。

## 四类 Type 契约浏览（2026-11-03）

新增四个入口：`#object-types`、`#link-types`、`#action-types`、`#function-types`。每个入口提供 JSON 定义、实例/记录、类型引用拓扑、深度剖析四个标签。点击实例可进入实际一跳业务图；类型拓扑是结构引用，不表示执行调用。

后端 `/api/ontology-manager/types?version=...` 复用所选版本的只读投影，补充 `web/type-definitions.json` 的讲解与示例。现有对象字段使用 observedTypes 标注观察来源，不伪装成完整声明式验证器。示例实例独立保存，既不混入 nodes/links，也不混入调用记录。

状态分为已实现、部分实现、设计示例，并附具体边界。当前本地 `submitForReview` 从 actions/submit-review.json 读取真实契约，区别于目标 `submitManualReview` 示例；类型浏览只读，正式执行入口属于另一个本地演示页面。

轨迹只返回白名单摘要；最多扫描最近 200 条 traces 后按语义版本过滤。独立动作审计最多展示最近 100 条，标明属于本地运行层而非某次历史语义版本。本地轨迹可能含评测，不代表生产请求；本地事务成功不代表外部退款、换货或转接成功。

## 拓扑页的拖动与详情

节点可直接拖动，所有关联边和关系标签跟随移动。拖动边或边上的文字可调整曲线走线，关系两端对象不会改变。点击类节点显示属性、关系和全部实例入口；点击实例节点显示原始内容及来源；点击边显示方向、关系类型、基数及匹配依据。详情以可收起浮层显示。

支持滚轮缩放、拖动画布与“重置布局”。当前页面会在切换视图后保留该版本／局部图的布局，刷新页面恢复默认；布局不写入本体、数据库或业务动作。边和节点支持 Enter／空格查看详情。

浏览器实测：节点位移后关联路径随之更新；边拖动后曲线变化但端点 ID 不变；拖动不会误触详情；缩放后仍可拖动；切换页面布局保留；重置恢复初始节点、边和视口。另验证 E25／3212 知识的局部图可打开来源证据边并查看两端对象。
