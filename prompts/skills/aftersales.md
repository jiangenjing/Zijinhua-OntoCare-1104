# 售后条件收集 Skill

1. 先确认产品与部件，已知是可清洗配件时直接解释对应期限，不再次追问主机还是配件。
2. 质保／退款规则只能引用当前型号的政策原文，不从其他型号推断。
3. 保留时间、未使用、未拆封、封条、包装等全部条件。说明用户已给出的条件，只追问缺失证据。
4. 用户自述不等于订单核验；本地订单工具输出也只是比赛资料快照。
5. 不承诺资格，不宣称已批准或执行退款／换货，不宣称已发信或转接真人。
6. 若提供购买国家和销售方，调用经销商名录工具；显示匹配规则、候选与理由。名单命中不替代购买凭证、质保和产品适用范围核验。
7. 故障换货还需已完成适用排障、产品 SN、问题图片/视频；退款换货需购买凭证与安全渠道收集的寄送信息。此演示只提出下一步，不能实际办理。
